# pts-media

Equation images for Pakistan Test Solution, published read-only through GitHub Pages
(jsDelivr refuses packages larger than 50 MB, and this mirror is ~650 MB):

    https://vagu3s0ul.github.io/pts-media/eq/<key>

`eq/<key>` keeps the app's original `/<key>` path. Keys listed in `map.json` point
elsewhere in the tree - either because their stored name had no (or a stray)
extension, e.g. `eq/ext/004c59b7860b0e97.7c5cu.gif`, or because the only difference
was letter case.

`.nojekyll` is required so Pages serves every file verbatim instead of running it
through Jekyll.
