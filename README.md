# pts-media

Equation images for Pakistan Test Solution, published read-only through GitHub Pages
(jsDelivr refuses packages larger than 50 MB, and this mirror is ~650 MB):

    https://vagu3s0ul.github.io/pts-media/eq/<key>

Every key is stored at its exact path, including spellings that differ only in
letter case. Keys listed in `map.json` point elsewhere because their stored name
had no, or a stray, image extension, e.g. `eq/ext/004c59b7860b0e97.7c5cu.gif`.

`.nojekyll` keeps Pages from running the tree through Jekyll.
