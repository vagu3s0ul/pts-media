# pts-media

Equation images for Pakistan Test Solution, served read-only via jsDelivr:

    https://cdn.jsdelivr.net/gh/vagu3s0ul/pts-media@main/eq/<key>

`eq/<key>` keeps the app's original `/<key>` path. Keys listed in `map.json`
point elsewhere in the tree - either because their stored name had no (or a
stray) extension, e.g. `eq/ext/004c59b7860b0e97.7c5cu.gif`, or because the
only difference was letter case.
